# SmartTrader Font Standard

## Canonical Pair (Frozen)
- Sans UI font: `IBM Plex Sans`
- Mono numeric font: `DM Mono`

## Rules
- Do not add alternate font families.
- All UI/body text uses `--font-sans`.
- Prices, percentages, and financial metrics use `--font-mono` with tabular numbers.

## Runtime Source
- Font loading: `frontend/app/layout.tsx`
- Token mapping: `frontend/app/globals.css`
- Canonical design reference: `docs/DESIGN_SYSTEM.md`
